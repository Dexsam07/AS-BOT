## Dependency-backed audit result

With the declared dependencies installed, the compatibility loader registered **838 commands** from the plugins directory and skipped **708 file-level registrations/imports**. The loaded commands are available to the live menu and router. The skipped set contains files that depend on removed legacy modules, unavailable third-party packages, or non-command background plugins. These files remain disabled rather than being allowed to crash the bot. Some legacy files also start their own timers/listeners at import time, so the audit process may not exit by itself; production startup remains a supervised long-running process.

The runtime therefore enables all plugins that successfully register through the supported `cmd`, `bandah`, `gmd`, `malvin`, `amon`, or `shyam` compatibility APIs, while reporting incompatible files in startup logs. Duplicate command names are ignored in favor of the first registered command, protecting built-in security and owner controls.
